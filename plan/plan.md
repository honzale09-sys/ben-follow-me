# FollowMe web – zveřejnění beze změn

Hotový web FollowMe z nahraného archivu followme-web.zip se zprovozní tak, jak je, a zveřejní se na trvalé adrese.
Obsah, texty ani vzhled se nemění. Cílem je co nejnižší spotřeba kreditů.

## Pro koho
Pro majitele webu FollowMe a pro jeho návštěvníky, kteří potřebují stránku najít na veřejné adrese.

## Hlavní funkce a zážitek
- Web se zobrazí přesně podle souborů v archivu: stránky, obrázky, styly a skripty.
- Odkazy mezi stránkami fungují i po zveřejnění.
- Web je dostupný na trvalé veřejné adrese.

## Průchod uživatele
1. Návštěvník otevře veřejnou adresu.
2. Uvidí úvodní stránku z archivu.
3. Prochází web stejně jako u původních souborů.

## Vzhled a dojem
Beze změny. Vzhled zůstává přesně podle archivu.

## Fáze
1. **MVP (stavím teď):** rozbalit archiv, zprovoznit web beze změn, krátce ověřit, že se načítá, a zveřejnit ho na trvalé adrese.
2. **Volitelně později:** opravit chyby, které by bránily zobrazení, pokud se nějaké objeví.
3. **Volitelně později:** úpravy obsahu nebo vzhledu, vlastní doména.

## Předpoklady
- Archiv obsahuje hotový web, který jde zobrazit bez dalšího programování.
- Pokud archiv obsahuje i serverovou část (např. formuláře nebo databázi), zprovozní se jen v nezbytném rozsahu, aby web běžel. Nic dalšího se nepřidává.
- Testování bude co nejjednodušší (jeden náhled stránky) kvůli úspoře kreditů.
- První zveřejnění stojí 50 kreditů. Uživatel s tím souhlasil.
- Použije se výchozí adresa od Emergent, ne vlastní doména.
